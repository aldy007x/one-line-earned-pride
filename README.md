A make.fun bounty entry for "One Line of Earned Pride" (slug `u-mang-one-line-of-earned-pride-a0138557`).

The program writes a single original line of text — one quiet, earned moment of pride for a young person in a concrete everyday scene, where months of hard early-morning effort finally land and are noticed without fanfare. No trophy, podium, or graduation imagery.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/path/to/output python3 main.py
```

The program is deterministic, uses only the Python standard library, and makes no network calls. It writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (creating the directory if needed) and performs a runtime self-check: the output must be exactly one non-blank line of 1–240 characters, otherwise it exits non-zero.
